# ModSync 🎮

**Автоматическая синхронизация модов Minecraft с HTTP-сервером**

ModSync - это утилита для автоматической синхронизации модов Minecraft между сервером и клиентом. Программа загружает новые моды с HTTP-сервера и удаляет устаревшие, обеспечивая актуальность модпака.

---

## ✨ Возможности

- 🔄 **Автоматическая синхронизация** - скачивание новых модов с HTTP-сервера
- 🗑️ **Удаление устаревших модов** - автоматическое обнаружение и удаление модов, которых нет на сервере
- 📦 **Простая настройка** - JSON конфигурация с адресом сервера
- 🖥️ **Графический выбор папки** - удобный диалог выбора директории Minecraft
- 📊 **Детальное логирование** - отслеживание процесса синхронизации с помощью Serilog
- �� **Асинхронная загрузка** - быстрая загрузка файлов

## 🚀 Быстрый старт

### Требования

- .NET 6.0 или выше
- Windows (использует Windows Forms для выбора папки)
- HTTP-сервер с модами (например, `https://example.com/mods`)

### Установка

1. Скачайте последний релиз из раздела [Releases](../../releases)
2. Распакуйте архив в любую папку
3. Отредактируйте файл `config.json`, указав адрес сервера с модами

### Настройка

Откройте файл `config.json` и измените параметр `Server`:

```json
{
  "ModFolder": "",
  "Server": "https://example.com/mods"
}
```

**Параметры:**
- `ModFolder` - путь к папке с модами Minecraft (оставьте пустым для выбора через диалог при первом запуске)
- `Server` - **URL сервера с модами** (должен возвращать HTML-страницу со ссылками на .jar файлы)

> ⚠️ **Важно:** Укажите URL сервера, с которого будут загружаться моды (например: `https://example.com/mods`)

## 💻 Использование

1. Запустите `ModSync.exe`
2. При первом запуске выберите папку с модами Minecraft через диалоговое окно
3. Программа автоматически:
   - Просканирует указанный HTTP-сервер
   - Найдёт все доступные .jar файлы (моды)
   - Сравнит их с локальными модами
   - Скачает новые моды
   - Удалит устаревшие моды

## 🔧 Настройка сервера

ModSync работает с любым HTTP-сервером, который предоставляет список файлов в виде HTML. Программа парсит HTML-страницу и ищет все ссылки на `.jar` файлы.

### Пример структуры сервера

```
https://example.com/mods/
├── jei-1.19.2.jar
├── optifine-1.19.2.jar
├── journeymap-1.19.2.jar
└── ...
```

### Поддерживаемые типы серверов

- ✅ Apache Directory Listing
- ✅ Nginx autoindex
- ✅ Любой статический файловый сервер с HTML-листингом
- ✅ Простая HTML-страница со ссылками на .jar файлы
